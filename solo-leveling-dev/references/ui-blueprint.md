# Solo Leveling UI Blueprint

## Color Palette (CSS Variables)
- `--bg`: #06040f (Deep Abyss)
- `--bg2`: #0c0920 (Shadow Slate)
- `--panel`: #0f0d20 (Hunter's Panel)
- `--border`: #2a2060 (Mana Glow)
- `--purple`: #7a5fff (System Primary)
- `--gold`: #f5c842 (S-Rank Gold)
- `--green`: #4de89a (Quest Success)
- `--text`: #e8e0ff (Mana White)

## Typography
- **Title**: 'Cinzel', serif (Ancient Runes)
- **Mono**: 'Share Tech Mono', monospace (System Readout)
- **Body**: 'Rajdhani', sans-serif (Modern Interface)

## Key Components
- **SystemHeader**: Animated [ system online ] blinker, Rank label, and User name.
- **StatGrid**: 4-column layout for Level, EXP, Quests, and Streak.
- **ExpBar**: Linear gradient bar (`#2d1fa0` -> `#a99eff`) with shine animation.
- **QuestCard**: Collapsible glass-morphism panels with progress mini-bars.
- **TaskRow**: Checkbox with strike-through and green highlight on completion.
